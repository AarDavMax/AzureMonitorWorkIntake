# Azure Monitor Documentation Requests

Use this guide when you need to request a documentation fix for Azure Monitor content.

## Request a documentation fix

Select the applicable AKA link for the Azure Monitor subservice and complete the short work item form.

Subservices are defined by the first path segment after `/azure-monitor/` in the Learn URL.

Example:

```text
https://learn.microsoft.com/azure/azure-monitor/alerts/alerts-types
```

In this example, the subservice is `alerts`.

The Azure Monitor documentation team handles product documentation published under:

```text
https://learn.microsoft.com/azure/azure-monitor
```

Instructions on finding the owner of any article can be found [here](https://aka.ms/InternalFindFeatureOwnerFromLearnArticle).

Azure Service Health and Azure Advisor aren't supported by the Skilling org for documentation requests.
